# Wine Classification Using Decision Trees

## Project Overview

This project applies Decision Tree Classification to the Wine dataset from Scikit-learn. The objective is to classify wine samples into three different classes based on their chemical measurements.

The project compares the Gini and Entropy splitting criteria and evaluates different maximum tree depths to understand their effect on classification accuracy.

## Problem Statement

Build a Decision Tree Classifier that predicts the class of a wine sample using its chemical properties.

The experiments investigate how the splitting criterion and tree depth influence predictive performance.

## Dataset

- **Dataset:** Wine Recognition Dataset
- **Source:** `sklearn.datasets.load_wine`
- **Samples:** 178
- **Input features:** 13
- **Target classes:** 3
- **Problem type:** Multiclass Classification

The dataset includes chemical measurements such as alcohol, malic acid, ash, color intensity, and flavanoids.

## Project Workflow

1. Loaded the Wine dataset using Scikit-learn.
2. Explored the dataset structure, features, and class distribution.
3. Split the data into training and testing sets using stratified sampling.
4. Trained Decision Tree Classifiers using Gini and Entropy.
5. Experimented with maximum tree depths of 2, 4, and 6.
6. Compared the test accuracy of all six configurations.
7. Selected the highest-accuracy configuration for further evaluation.
8. Evaluated the selected model using a classification report and confusion matrix.
9. Visualized the decision tree and feature importances.
10. Summarized the findings and potential improvements.
